# 交叉引用對照表

本文件由 `node tools/check-refs.mjs` 生成，不要手改。

正文裏的「第 X 條」只記條號不記內容，插入或刪除條目會讓後面的引用集體錯位，
而錯位後的條號往往仍在範圍內，光查越界抓不到。所以把每處引用**實際指向的標題**
攤開寫在這裏併入庫：改完條目重新生成，`git diff` 裏凡是條號沒動而標題變了的，
就是被順延撞歪的引用。

另一道保險是**錨點**：每處引用的前後文裏都得有一個詞和目標條目標題對得上
（「醫療救助見第 11 條」裏的「醫療救助」，或顯式寫成「見第 16 條（借條和擔保）」）。
`node tools/check-refs.mjs --check` 會把沒有錨點的裸條號判為失敗——那種引用一旦
被撞歪，對照表的 diff 也看不出異常，只能靠錨點兜住。

錨點算不算數按長度和距離判：整句裏連着三個漢字和標題對上（「含糖飲料」「居民醫保」），
或者引用所在的那個逗號分句裏有兩個漢字對上，才算實錨點；只在分句之外撞上兩個常見漢字
（「自己」「公司」）的，按沒有錨點處理。這道加嚴是 2026-09-20 補的：第 31 節插條目時
「……的貸款見本節第 15 條」被順延撞到新條目「在家給境外公司遠程做事……個稅自己報」上，
隔着兩個逗號的「你自己還」冒充了錨點，`--check` 當時報的是通過。
