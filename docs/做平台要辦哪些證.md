# 做平台要辦哪些證：對照表與選伺服器的決策表

這篇長文對應 README 第 26 節。這裏只放三張表和幾段最容易搞錯的說明。條目正文和來源都在 README 裏。公司怎麼註冊、怎麼報稅，見第 12 節（創業與做生意）。受僱的技術人員別踩的那些線，見第 11 節（程序員和技術人）。

## 一、先判斷你做的是哪種業務

一個站點常常同時沾上好幾類業務。沾上幾類，就得辦幾張證。不是挑一張辦了就完事。

| 你在做的事 | 對應業務類別 | 要甚麼 | 主要依據 |
|---|---|---|---|
| 不收錢的資訊站、個人網誌、公司官網 | 非經營性互聯網資訊服務 | ICP 備案。它不是許可證，是開站前向主管部門報個到 | 互聯網資訊服務管理辦法第四條 |
| 向用戶收錢的會員、增值服務、付費內容 | 經營性互聯網資訊服務 | 增值電信業務經營許可（資訊服務業務）。管的是你向用戶收錢這件事 | 同上第三、四、七條 |
| 給買賣雙方牽線、處理交易和訂單 | 在線數據處理與交易處理業務 | 增值電信業務經營許可（B21）。管的是你替買賣雙方處理交易 | 電信業務分類目錄（2015 年版）B21 |
| 有主播出鏡的直播、遊戲直播 | 網絡表演 | 網絡文化經營許可證，經營範圍含網絡表演。沒有它，站上不能讓主播出鏡 | 網絡表演經營活動管理辦法第四條 |
| 自己做影片節目，或者把別處的節目匯在一起，或者讓用戶往站上傳影片 | 互聯網視聽節目服務 | 資訊網絡傳播視聽節目許可證。管的是站上播影片節目 | 互聯網視聽節目服務管理規定第七、八條 |
| 在直播裏帶貨賣東西 | 網絡直播營銷 | 該辦的證照按上面幾行辦。另外還要核驗商家、留存記錄 | 網絡直播營銷管理辦法（試行）第八條 |
| 做新聞資訊 | 互聯網新聞資訊服務 | 互聯網新聞資訊服務許可證。沒有它，站上不能發新聞 | 互聯網直播服務管理規定第五條 |
| 自建機房賣主機、賣帶寬 | 互聯網數據中心業務、互聯網接入服務業務 | 增值電信業務經營許可（B11、B14）。管的是你把機房和帶寬賣給別人 | 電信業務分類目錄（2015 年版）B11、B14 |

哪種直播對應哪張證，七部門 2021 年那份指導意見說得最直白：「開展經營性網絡表演活動的直播平台須持有《網絡文化經營許可證》並進行ICP備案；開展網絡視聽節目服務的直播平台須持有《資訊網絡傳播視聽節目許可證》（或在全國網絡視聽平台資訊登記管理系統中完成登記）並進行ICP備案；開展互聯網新聞資訊服務的直播平台須持有《互聯網新聞資訊服務許可證》。」

說白了是三種。有主播表演的，辦《網絡文化經營許可證》。做網絡視聽節目的，辦《資訊網絡傳播視聽節目許可證》，或者在全國網絡視聽平台資訊登記管理系統裏完成登記。做新聞的，辦《互聯網新聞資訊服務許可證》。前兩種還都要做 ICP 備案。

### 三個容易搞錯的點

**個人身份辦不了增值電信許可。** 申請條件第一項就寫着「經營者為依法設立的公司」。也就是說，你得先有一家公司。個人拿身份證去申請，辦不下來。只在本省經營的，公司註冊資本不能低於 100 萬元。跨省經營的，不能低於 1000 萬元。材料交上去，主管部門的審查期限是 60 日。證拿到手，有效期 5 年。想做收費的業務，就得先把公司開起來。怎麼開公司見第 12 節（創業與做生意）。

**視聽節目那張證，民營公司基本拿不到。** 申請條件寫的是「具備法人資格，為國有獨資或國有控股單位」。意思是這張證只發給國家出資或者國家控股的單位。所以做長影片、做自製節目這條路，對個人創業者是關着的。想做直播，走的是網絡文化經營許可證那條線。

**沒有哪份官方文件明說「電商平台必須辦 EDI」。** EDI 指的就是上表裏 B21 那一類許可，正式名稱叫在線數據處理與交易處理業務。工信部的辦事指南只說一句「按照業務界定申請相應的電信業務經營許可」。工信部還單獨答覆過兩回：網約車平台只需做網站備案，權益類和大宗商品交易平台也只需做網站備案。所以本書只照抄 B21 的定義原文。具體到你這門生意該不該辦，留給你和當地的通信管理局判斷。動手辦之前，先給屬地通管局打一次電話問清楚。

## 二、平台自己的日常義務

拿到證，只是允許你開張。下面這些是開張以後天天要做的事。做不到會罰多少錢，寫在第 26 節各條裏。

| 義務 | 硬指標 | 出處 |
|---|---|---|
| 核對並登記在你平台上開店的商家 | 至少每六個月重新核對更新一次 | 網絡交易監督管理辦法第二十四條 |
| 把商家的身份資訊報上去 | 每年 1 月和 7 月報給市場監管部門 | 同上第二十五條 |
| 把跟稅有關的資訊報上去 | 每個季度結束後的下一個月內報給稅務機關 | 互聯網平台企業涉稅資訊報送規定第四條 |
| 留存交易資訊 | 從交易完成那天起不少於三年 | 電子商務法第三十一條 |
| 留存直播內容和日誌 | 六十日 | 互聯網直播服務管理規定第十六條 |
| 留存網絡表演的影片 | 不少於六十日 | 網絡表演經營活動管理辦法第十三條 |
| 留存網絡日誌 | 不少於六個月 | 網絡安全法第二十三條第三項 |
| 處理侵權通知 | 把商家的聲明轉給投訴方。轉過去滿十五日還沒有下文，就恢復 | 電子商務法第四十三條 |
| 設投訴舉報入口 | 放在顯眼的位置，點起來方便 | 網絡資訊內容生態治理規定第十六條 |

留存期限有四套，各走各的鐘。交易資訊存三年。直播內容存六十日。網絡日誌存六個月。平台上商家的身份資訊，從他退出平台那天算起，存三年。做存儲方案時按最長的那條設計，別按最短的。

## 三、選伺服器：三檔怎麼挑

先回答下面幾個問題，再去比價格。

| 問題 | 如果答案是 | 那就 |
|---|---|---|
| 站點停一天你受不受得了 | 受得了 | 最便宜的 VPS，也就是虛擬伺服器，就夠用 |
| 有沒有用戶註冊、交易、上傳 | 有 | 用主流雲廠商的雲主機。挑能隨時備份整機、也能臨時加配置的 |
| 有沒有專人管伺服器 | 沒有 | 別碰把整台機器託管在機房那條路 |
| 帶寬或硬件是不是最大頭的開銷 | 是，而且有專人管 | 這時才考慮把整台機器託管在機房 |

**小服務商不是不能用，是用之前要先查證。** 把機器託管在機房、給別人提供上網接入，這兩件事本身就要許可證。它們屬於增值電信業務。查法是打開工信部的電信業務市場綜合管理資訊系統 tsm.miit.gov.cn，按公司全稱查一次。查不到證的，直接排除。價格能便宜一半的那種，風險通常是三樣。一是機器賣超了。二是老闆跑路。三是上游被封。真出了這三樣事，服務商有證，你還能投訴到通信管理局。服務商沒證，你連找誰申訴都不知道。

**放境內還是放境外。** 伺服器放在境內，就要做備案。接入商不許給沒備案的站點提供接入。放到境外，確實能繞開備案。但你的用戶在境內，收的錢也在境內。第 26 節第 5 到第 10 條寫的那些平台義務，一條都少不了。放境外還要多擔一層數據出境的成本。把境內用戶的個人資訊傳到境外的機器上，這就叫出境。出境要滿足個人資訊保護法第三十八條列的四項條件之一。還要單獨取得本人同意。單獨的意思是，不能混在一攬子協議裏讓人一起點了。涉及多少人，按「自當年 1 月 1 日起累計」算。不滿 10 萬人的，下面三條路都不用走。10 萬到 100 萬人的，要麼簽標準合同，要麼去做認證。100 萬人以上的，要申報安全評估。

**備份。** 備份至少放在兩個地方。而且別把兩份都放在同一家服務商的同一個區域。這一條沒有法規依據，純屬經驗。
