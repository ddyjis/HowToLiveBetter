# 高性價比人生指南

講怎麼活得久、怎麼少生病，出了意外怎麼救。講怎麼少花冤枉錢，哪些事會讓人被騙、攤上官司。講沒工作沒錢時能去領甚麼，開店、開公司、做網站要辦甚麼手續。也講戀愛結婚生孩子、出國和學手藝。<br>
574 條建議，每條寫明花掉甚麼、換回甚麼、證據有多硬，來源只引期刊論文和官方文件。

不用全做：這是按性價比排好的備選單，不是任務清單——挑走一兩條就算數，作者自己也沒做到其中大部分。

## 怎麼讀

- **不用全做**：這是一份按性價比排好的備選單，不是任務清單。挑走一兩條就算數，剩下的放着，需要時再回來查。「說着容易做着難」這個評價是對的——作者自己也沒做到其中大部分，寫下來是為了要用的時候找得到。想挑省力的，看下面「只想看最值得做的」那條。
- **想按條件挑**：打開[在線檢索頁](https://eternity4719.github.io/HowToLiveBetter/)，可以按關鍵詞、章節、證據等級來篩，也可以按「花不花錢、花多少時間、要不要毅力」這三樣篩，幾個條件能疊着用。頁面上的內容直接取自 book/ 目錄裏的正文，正文一改，頁面跟着改。
- **條目之間會互相指路**（「見第 8 節第 17 條」這種）：在檢索頁裏，這種指路帶一條虛線。點一下，就地顯示被指的那條的標題和「說人話」。想真的翻過去，再按「跳過去」。那一條正好被篩選條件藏起來了，頁面會自動把篩選清掉。在 GitHub 上直接讀正文點不動，但每處指路後面都寫着指向甚麼（「見第 18 條（借錢寫清借條）」）。不翻過去也知道說的是哪條。
- **想按順序讀**：每節內的條目按性價比從高到低排列，從每節前幾條開始看就行。
- **想讓 AI 幫你查**：倉庫裏帶了一個中文 skill（[skills/life-decision-guide](skills/life-decision-guide/)），Claude Code 和 Codex 都能裝。裝上以後直接問「替朋友擔保簽不簽」「每天通勤兩小時值不值」。它會先把相關條目從正文裏查出來，再照書裏的算賬方式排序回答，並註明出自第幾節第幾條。查不到就說查不到，不自己編數字。裝法見 [那個目錄的說明](skills/life-decision-guide/README.md)。
- **想離線看、想發給別人**：下載 [離線單文件 HTML](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.html)，整本書連同檢索和篩選都在這一個文件裏，雙擊就開，不用伺服器也不用聯網，微信裏也能直接傳。
- **想打印或在手機上翻**：下載 [PDF](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.pdf)，A4 排版、兩百多頁，帶目錄頁碼和書籤，每節另起一頁。
- **想在 Kindle 或其他閱讀器上讀**：下載 [EPUB 電子書](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.epub)，Kindle 用 Send to Kindle 發過去即可。
- **三樣都是正文每次更新後自動重新生成的**，下載鏈接固定不變；轉發出去的那一份不會跟着更新，以在線版為準。
- **看不懂那串數字**：每條都有一行「說人話」。它把「收益」欄裏那些研究裏的寫法，翻成「同期死亡的概率低約兩成」「拘留幾日、罰多少錢」這樣的日常說法。它只用「收益」欄已經寫到的內容，不添新數字。只看這一行就夠拿主意。「收益」欄里原樣留着全部數字，想自己核對就看那一欄。
- **只想看結論最硬的**：在檢索頁裏勾選證據等級 A，只留下有具體數字、來自薈萃分析或大型試驗的 385 條。
- **只想看最值得做的**：勾選性價比「極高」，得到 105 條既不花錢、不花時間、不需要毅力，收益又落在最大一檔的條目。再疊加一個「換回甚麼」，就是該口徑下的優先清單。
- **看到「不要」開頭的節標題不用緊張**：節標題說的是這一節想防住的事（不要早死、不要浪費時間），不是說底下每條都在讓你別幹甚麼。真正要做的動作寫在條目標題裏，一律動詞開頭，自己就寫清了是「做甚麼」還是「別做甚麼」。同一節裏兩種都有：第 4 節既有「把『打算做』寫成『幾點、在哪、遇到甚麼就做甚麼』」，也有「不看電視和滾動新聞」。按條目標題讀，不用往節標題的語氣上套。

每條建議長這樣：

```markdown
### 5. 把家裏的食鹽換成低鈉鹽（鉀鹽）
- 成本：一袋比普通鹽貴幾元。買的時候順手換，不額外占時間。口味幾乎不變。
- 說人話：兩萬人的隨機試驗裏，把家裏的鹽換成低鈉鹽的人，五年內死亡的概率低約 12%，中風低約 14%。這是隨機分成兩組比出來的，比只跟蹤記錄得到的數字更可信。
- 收益：一項把人隨機分成兩組的試驗，在中國農村做的，20995 人，都是得過卒中的人或者 60 歲以上的高血壓病人，跟蹤了 4.74 年。結果：用低鈉鹽的那組比用普通鹽的那組，死亡風險低約 12%（RR 0.88）。卒中低約 14%（RR 0.86）。主要心血管事件低約 13%（RR 0.87）。
- 證據等級：A
- 來源：Neal B 等 (2021). Effect of Salt Substitution on Cardiovascular Events and Death. NEJM. https://doi.org/10.1056/NEJMoa2105675
- 備註：爭議。試驗對象是高危老人，健康年青人換鹽得到的好處要小得多。腎功能不全的人，或者正在吃保鉀類藥物的人，換鹽前先問醫生。
```

## 自己跑一份

多數人用不着部署：[在線檢索頁](https://eternity4719.github.io/HowToLiveBetter/)是現成的，要離線就下[離線單文件 HTML](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.html)，雙擊就開。

真要在自己電腦或伺服器上跑：

```bash
git clone https://github.com/eternity4719/HowToLiveBetter.git
cd HowToLiveBetter
python -m http.server 8000
```

然後瀏覽器開 `http://localhost:8000/`。檢索頁是純靜態的，`README.md` 和 `book/` 就是它的數據，沒有後端、沒有資料庫、不用裝依賴；把整個目錄丟給任何靜態伺服器（Nginx、GitHub Pages、對像存儲）效果一樣。注意 `index.html` 必須經 http 打開，直接雙擊本地文件會空白——瀏覽器不許網頁讀本地文件，那種場景請用上面的離線單文件版。

### 逐條閱讀頁和解析語料

倉庫還帶了一個 Next.js 逐條閱讀頁：首頁按章節列出全部條目，點擊後每條都有自己的地址（例如 `/items/e-1-1`）。從倉庫根目錄運行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打開 `http://localhost:3000/`。生產構建和啟動：

```bash
pnpm build
pnpm start
```

`pnpm dev` 和 `pnpm build` 會先運行 `tools/parse-corpus.mjs`。它按 README 的目錄動態找到章節和直接鏈接的長文，生成 `dist/book.json`，所以新增章節後不需要改前端文件名單。`dist/` 是生成目錄，不要手改或提交。上游更新後，rebase 完再運行 `pnpm build`，頁面就會按新正文重新生成。詳細說明見 [web/README.md](web/README.md) 和 [tools/parse-corpus.md](tools/parse-corpus.md)。

### 香港正體正文

香港正體中文是這個 fork 對外維護的唯一正文。繁化姬的候選譯本和 `translation-manifest.json` 只暫存在已忽略的 `dist/zh-HK/`；檢查它的 diff 後，`node tools/promote-hk.mjs --force` 會將譯本提升到根目錄的 README、`book/`、`docs/` 和本地連結的 Markdown。

```bash
node tools/convert-hk.mjs --force
node tools/promote-hk.mjs --force
```

先用 `node tools/convert-hk.mjs --dry-run` 查看會轉換的文件。不要手改生成的譯文；檢查後只提交根目錄的正體正文。完整流程和 API 來源見 [tools/convert-hk.md](tools/convert-hk.md)。

想自己生成三樣電子版（平時用不着，Release 裏的就是自動生成的）：

```bash
cd tools/epub && npm ci && npm run build   # EPUB
node tools/offline/build.mjs               # 離線單文件 HTML
node tools/pdf/build.mjs                   # PDF，另需 pandoc ≥ 3.1 和 typst ≥ 0.13
```

產物都在 `dist/`。

## 四種資源

這本書想幫你多留住的不只是壽命，一共四樣東西：

- **壽命**：活得更久，少死於本來可以避免的事
- **時間與精力**：活着的時間不花在沒有回報的事上，每天的注意力和體力少被白白耗掉
- **金錢**：少花冤枉錢，把錢花在收益確定的地方
- **人身自由**：不因為不知道一條紅線，把自己送進拘留所或者看守所

每一條建議都回答兩個問題：要花掉甚麼（錢/時間/精力/毅力），能換回甚麼（總死亡率變化 / 特定死因下降 / 時間與精力節省 / 金錢節省 / 保障與人身自由）。條目按性價比排，不按類別排：幾乎不花甚麼成本、換回的好處又大的，放在最前面。

**一條建議的好處落在誰身上，是分檔的。** 按「這份好處將來有多大可能回到你自己身上」從高到低：① **你自己**；② **配偶和直系親屬**（父母、子女、祖父母外祖父母、孫子女外孫子女）；③ **朋友、同事和其他親屬**——互惠關係，幫出去的將來可能回來；④ **陌生人**——最低一檔，但不是零：回報的概率小，而且你不了解對方性格，還有被訛、被反咬、被報復的一面。不同檔不合併計算，寫到第 ④ 檔時好處和風險一起寫。

急救那一節照這個讀：中國 38,227 例院外心臟驟停裏 79.2% 發生在家裏，學按壓首先是為了按在自家人身上；「看到有人溺水自己不下水」「撞見鬥毆別上手拉架」這類規則本身就是自保規則，防的是你從旁觀者變成第二個傷者。對陌生人要不要出手是你自己的權衡，條目會把免責條款、自保動作和風險面都寫清楚，不替你把它算成非做不可的理由。

死亡率的數字、時間精力的數字、金錢的數字和法律後果，各算各的，不互相折算。這四樣對應檢索頁上那四個「換回甚麼」，彼此之間不比大小。

## 證據分級

每條建議都標註證據等級：

| 等級 | 含義 |
| --- | --- |
| A | 有具體數字可查，出處是多項研究合併起來的薈萃分析、跟蹤很多人很多年的大型隊列，或者隨機分組的試驗（RCT），能說出降了多少（HR、RR、下降百分比） |
| B | 有研究支持，但說不出一個確切數字；或者只有小樣本、單獨一項研究撐着 |
| C | 作者自己的經驗，或者大家公認的做法，沒有直接的研究文獻 |

全書 574 條中 A 級 385 條、B 級 139 條、C 級 50 條，另有 51 條標註了爭議、38 處標註了 TODO 待核實。有爭議的 A/B 級條目會標註「爭議」並列出反方證據。所有來源只引原始文獻（期刊論文附 DOI 或 PubMed 鏈接，或 WHO/CDC/國家統計局等官方機構報告），不引二手轉述。不確定的數字標「待核實」。

## 性價比檔

證據等級只回答「這個數字可不可信」，不回答「這件事值不值得做」。所以每條還另外標了兩樣：收益量級（好處有多大）和口徑（換回的是哪一類東西）。檢索頁拿這兩樣加上三項成本，合出一個性價比檔：

| 維度 | 取值 | 怎麼定的 |
| --- | --- | --- |
| 口徑 | 換壽命 / 換錢 / 換時間精力 / 換人身自由 | 看這條主要換回的是甚麼。**不同口徑之間不做比較**，「總死亡率降 12%」和「每年省 500 元」不在一把尺子上，沒法分高下 |
| 收益量級 | 大 / 中 / 小 | 盡量照着條目自己的「收益」欄，按事先定好的界線套，不憑感覺：換壽命看降了百分之幾（≥20% 為大，10–20% 為中，<10%、或者只量到中間指標而沒量到最終結果的為小）；換錢看金額（萬元級為大，數百到數千為中，幾十元為小）；換人身自由看後果（避免刑事責任為大，避免拘留或行政處罰為中，避免民事糾紛為小）；換時間精力看省下多少（每天省出小時級為大，每週小時級為中，只省一次的為小） |
| 性價比 | 極高 / 高 / 一般 | 好處大、三項成本又全是零 = 極高；好處大、成本不高，或者好處中等、成本為零 = 高；剩下的 = 一般 |

全書 574 條中性價比極高 105 條（18%）、高 266 條（46%）、一般 203 條（36%）。中間那檔條數多是有意的：底下的收益量級本來就只分大、中、小三級，再往細裏切就是裝出來的精確。

**這一檔是作者自己的判斷，不是證據**，按本書的標準它本身只算 C 級；它和證據等級是兩回事，誰也不影響誰。一條可以證據是 A 級、性價比卻只算一般（帶狀疱疹疫苗有 97.2% 效力的三期 RCT，但兩針三四千元、帶狀疱疹很少致命），也可以證據只有 C 級、性價比卻極高（出境前把行程發給家人）。「一般」不等於不該做——全書的條目都是建議做的，只是這一檔得你自己掂量那筆花銷值不值。

## 讀懂數碼（術語表）

正文盡量用日常說法，但引用研究的時候免不了出現幾個統計名詞。看不懂就查這張表；在線檢索頁裏，把滑鼠停在帶虛線的詞上（手機上點一下）也會彈出解釋。

<details>
<summary>展開 41 條術語（總死亡率、HR、RR、95% CI、薈萃分析、BMI、LPR、定金與訂金……）</summary>

| 術語 | 意思 |
| --- | --- |
| 總死亡率 | 一段時間裏，一群人當中死掉的人佔多大比例，不管死於甚麼原因。本書用它衡量「活得久不久」。研究原文裏叫全因死亡率，英文縮寫 ACM |
| HR | 風險比。同樣一段時間裏，做了某件事的那組人出事（死亡、得病）的快慢，除以沒做的那組。HR 0.87 就是比沒做的那組低 13%，HR 1.21 就是高 21% |
| RR | 相對風險。兩組人出事的可能性之比，數字怎麼讀和 HR 一樣 |
| OR | 比值比。也是兩組的對比，只是算法和 RR 略有不同：要比的那件事很少見時，它和 RR 差不多；那件事很常見時，它會把差距說得比實際大 |
| IRR | 發病率之比。發病率是一段時間裏新得這個病的人佔多大比例，兩組相除，讀法同 RR |
| RaR | 發生次數之比。比的是事情發生了多少次（比如摔了多少跤），不是多少人出事，讀法同 RR |
| 標準化死亡比 | 英文縮寫 SMR。這群人實際死了多少人，除以「同樣年齡的普通人本該死多少人」。5.86 就是死的人數是同齡人的 5.86 倍 |
| 風險差 | 兩組出事的概率相減，直接得出「每一千人裏多出幾個」。倍數只說翻了幾倍，風險差說的是實實在在多了多少人 |
| 95% CI | 95% 置信區間。研究算出的數字總有誤差，這是真實情況很可能落在的範圍。倍數類的數字，範圍跨過了 1；加減類的數字，範圍跨過了 0，就說明兩組的差別可能只是碰巧，文中會寫「無統計學意義」 |
| RCT | 隨機對照試驗。用抽籤一樣的辦法把人分成兩組，一組做這件事，一組不做，過後比結果差多少。要證明「是這件事起了作用」，這種做法最有說服力 |
| 薈萃分析 | 把很多項研究的結果湊到一起重新算，得出一個總的數字。也叫 meta 分析 |
| 隊列 | 隊列研究。挑一大群人跟蹤很多年，記錄誰出了事。能看出兩件事常一起出現，但不足以證明是前一件造成了後一件 |
| 觀察性 | 觀察性研究。研究者只在旁邊記錄，不安排誰做、誰不做。結果容易被別的因素帶偏（見本表的混雜、反向因果兩條），數字要打點折看 |
| 混雜 | 有第三個因素同時牽動着前因和後果，讓兩件事看起來像有因果。比如愛吃菜的人往往也更愛運動，分不清是哪一樣在起作用 |
| 反向因果 | 因果的方向弄反了：看着像前一件引起後一件，其實是後一件引起前一件。不是睡得多讓人早死，而是病重的人睡得多 |
| d、g | 效應量，表示兩組的差距有多大。把差距換算成「相當於幾倍的常見波動幅度」：0.2 算小，0.5 中等，0.8 大 |
| r | 相關系數。兩件事跟着一起變的緊密程度，取值從 -1 到 1，0.1 算弱、0.3 中等、0.5 算強 |
| MET | 運動強度的單位。安靜坐着是 1 MET，快走約 3 到 4 MET。寫成 MET·h，就是強度乘以做了幾小時，表示一共動了多少 |
| GRADE | 國際上通用的一套打分辦法，給一項證據有多可靠評級，分高、中、低、極低四檔 |
| 意向篩查分析 | 算效果時按「通知了誰去做篩查」算，不按「誰真的去做了」算。被通知的人裏總有沒去的，所以這種算法會把篩查對真去做的人的好處算低 |
| 包年 | 統計一個人一共抽了多少煙的單位。每天抽幾包乘以抽了幾年，30 包年就是每天一包抽了 30 年 |
| BMI | 體重指數，看胖瘦常用的一個數：體重的公斤數，除以身高米數的平方 |
| LDL | 低密度脂蛋白膽固醇，俗稱壞膽固醇 |
| eGFR | 估算腎小球濾過率，衡量腎臟過濾能力的一項指標，單位 mL/min/1.73 m²。數越低說明腎功能越差，慢性腎病分幾期就按它定 |
| HBsAg | 乙肝表面抗原，化驗單上的一項。結果是陽性，表示已經感染了乙肝病毒 |
| HPV | 人乳頭瘤病毒。它分很多型，其中一部分型長期感染會導致宮頸癌 |
| LDCT | 低劑量胸部 CT，輻射量約為普通 CT 的五分之一到十分之一 |
| PM2.5 | 飄在空氣裏的細顆粒物，直徑在 2.5 微米以下 |
| NOVA | 一種給食品分類的辦法，按加工得有多厲害分成四類，「超加工食品」就是其中的第四類 |
| LPR | 貸款市場報價利率。國內貸款利率的基準，每月 20 日公布一次，房貸利率和民間借貸的利息上限都照着它算 |
| 一裁終局 | 勞動仲裁的結果下來就直接生效，單位不能再拿這件事去法院起訴 |
| 粗結婚率、粗離婚率 | 每一千人裏，當年登記結婚、登記離婚的對數。另外還有個數叫離結比，是當年離婚對數除以結婚對數，和這兩個不是一回事，別混着看 |
| AED | 自動體外除顫器。公共場所常見的紅色或黃色急救箱，開機以後跟着語音提示做就行，要不要電擊由它自己判斷 |
| CPR | 心肺復甦。心臟驟停時用力按壓胸口，讓血繼續流動 |
| 3C 認證 | 中國強制性產品認證。列進目錄的那些產品，沒印這個標誌就不准出廠、不准賣 |
| ICP 備案 | 網站或 App 正式上線之前，到工信部的系統裏登記一道手續 |
| 等級保護 | 網絡安全等級保護制度。按一套系統有多重要分成幾個級別，級別越高，要做的安全措施越多 |
| GPL | 一種開源許可證。用了這類代碼做出來的東西，往外發的時候通常也得把自己的代碼一起公開 |
| 競業限制 | 和公司簽的一種約定：離職後一段時間內不去同行的對手那裏上班。這段時間公司要按月給你補償，最長 2 年 |
| 認繳出資 | 註冊公司時承諾要投進去的錢。承諾了就得在法律定的期限內真掏出來，不是寫個數字好看 |
| 定金與訂金 | 兩個詞只差一個字，效力差很多：定金有罰則，收錢的一方反悔要雙倍退還，金額最多為合同額的 20%；訂金只是提前付的錢，反悔沒有這個罰則 |
